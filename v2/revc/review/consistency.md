# Rev C web set: consistency and fact-check audit

Read-only audit, 26 Sep 2026. No page or script was changed.

Pages checked: `v2/revc/web/{datasheet,verdict,changelist,manufacturing}.html`. The HTML was stripped to text with python, and SVG `aria-label`s, `alt` text and `href`s were checked separately.
Sources checked against: `v2/final/final_results.json` (and `pole_options_final.json`, `frame_sls_final.json`, `barrier_path_check.json`, `tread_box2.json`, `tread_grating.json`), `v2/revc/after_changes.json` (+ `after_changes.py`), `frame_after.json` (+ `.py`), `pole_fixing.json` (+ `.py`), the `build_*_revc.py` scripts, and `v2/spec/sheet_2026-09-23_events.txt`.

**R-number convention.** Every R-number on the pages is *file line − 1* of `sheet_2026-09-23_events.txt`. For example, R7 is line 8, "Gap between steps (open riser)", and R113 is line 114, "Area load 5.0–7.5 kN/m²". I checked all 30 R-numbers used on the pages. Each one points at a row about the stated topic. A few are loose fits, listed below. None is outright wrong.

Severity: **critical** means Gerald would draw something wrong or unsafe. **Major** means a contradiction, or text he cannot draw from. **Minor** means a rounding, wording or traceability problem.

## E. Terms Gerald cannot resolve from the text

These are the undefined or inconsistent terms, and where each one is used.

- **pitch line**: defined only in changelist F6. It is undefined on the datasheet and verdict.
- **net W**: datasheet rails. Not defined.
- **HAZ / f₀,haz**: datasheet material box. Not defined.
- **util / Use**: defined on the verdict and manufacturing guide. The datasheet uses "utilisation (demand ÷ resistance)". Acceptable.
- **ULS / SLS**: undefined on the datasheet.
- **T8.8**: datasheet; means EN 1999-1-1 Table 8.8. Cryptic.
- **J-notch**: undefined.
- **pivot posts**: F6. Undefined.
- **back box**: datasheet. Undefined.
- **left/right**: never defined (e.g. "facing up the stair").
- **x/y/z axes**: defined only for the tread.
